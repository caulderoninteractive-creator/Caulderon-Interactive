Support answers here match the current offline v0.10 build rather than the former pre-release assumptions about ads, purchases, or network services.

Does Ashen Crown need internet?

No. The current build is designed to run offline and does not request the Android Internet permission.

How does saving work?

Ashen Crown uses autosaves, lifecycle/quest saves, and manual saving from the pause flow. Progress is stored in the App’s private storage. Android may also back up app data if device/account backup is enabled.

My progress disappeared

Check whether App storage was cleared, the App was uninstalled/reinstalled, or the device restored a different backup. The current game has no Caulderon cloud account from which we can recover a missing server-side save.

The game is running slowly or stuttering

Open Settings and switch the target frame rate from 60 FPS to 30 FPS. The game also uses a bounded bitmap cache and low-memory trimming; closing other memory-heavy apps can help on constrained devices.

Can I change the camera?

Yes. Top-down is the default. The current build also includes an optional first-person exploration view, top-down zoom, and adjustable first-person field of view.

I reached a recovery screen

Ashen Crown can catch certain renderer/update failures and write a local diagnostic file named ashen_crown_runtime.log. If you contact support, include your device model, Android version, game version, what you were doing immediately before the issue, and—if you can access it—the relevant diagnostic details.

I have a billing or ad problem

The current v0.10 build has no ads and no in-app purchases. If you encounter a storefront claiming to sell in-game Ashen Crown currency or an “Remove Ads” entitlement for this build, contact us so we can investigate.

Contact Support

Email support@caulderoninteractive.com. Include “Ashen Crown” in the subject and, where relevant, your game version and Android device model.
