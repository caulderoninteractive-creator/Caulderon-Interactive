This policy reflects the actual v0.8 architecture: local SharedPreferences saves, six bundled campaigns, no network permission, no accounts, no ads, no billing, and no analytics.

Introduction

This Privacy Policy explains how Untold Realms (the “App”), developed by Caulderon Interactive, handles information. The current Android build is an offline anthology RPG and does not require a user account.

Information We Collect

Caulderon Interactive does not collect your name, email address, precise location, contacts, advertising identifier, payment information, or gameplay telemetry through the current App. The build includes no ads, billing, analytics, crash-reporting, account, or network SDK.

Data Stored on Your Device

The App stores autosaves, three manual Chronicle save slots, meta progression, campaign state, choices, inventory, quests, factions, relationships, companions, endings, and related preferences locally in Android app-private SharedPreferences using JSON serialization.

Internet and Third-Party Services

The current version does not request the Android Internet permission and does not contact a Caulderon Interactive backend. It contains no advertising or payment SDK. Google Gson is used only as a local JSON software library; using Gson does not itself transmit data to Google.

Device Permissions

The current Android manifest requests no runtime permissions. The App does not request location, contacts, camera, microphone, photos/media, files, notifications, advertising identifiers, or network access.

Android Backup & Restore

The current build allows Android’s standard app backup/restore mechanism. Depending on device and account settings, Android/Google may back up some app-private save data and later restore it. Caulderon Interactive does not operate that service and does not receive those backup contents.

Children’s Privacy

Untold Realms contains fantasy violence, horror, political conflict, identity themes, romance, tragedy, and other material intended for a general/teen-and-older game audience rather than a young-child audience. The current App does not collect personal information from players.

Your Choices and Data Deletion

  • Delete individual manual Chronicle saves from the App where available.
  • Clear the App’s storage in Android settings to remove local saves/meta data from the installed copy.
  • Uninstalling removes the installed local data; Android/Google backup copies, if any, are controlled through device/account backup settings.
  • Because we do not run player accounts or a gameplay-data server for the current App, we normally do not possess a server-side player profile to export or delete.

Changes to This Policy

If a later release adds online campaigns, cloud sync, advertising, purchases, analytics, accounts, or new device permissions, this policy and the store disclosures will be updated.
