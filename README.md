# Caulderon Interactive — GitHub Pages

Static website for Caulderon Interactive and Number Run: Pro Edition.

Live at: https://caulderoninteractive-creator.github.io/Caulderon-Interactive/

## Files
- index.html — main site (now links out to the live Google Play listing)
- privacy.html — hosted privacy policy matching the current app policy
- terms.html — hosted terms matching the current app terms
- support.html — player support and FAQ
- about.html — developer/about information
- copyright.html — copyright and third-party credits
- styles.css — site styling
- script.js — year footer
- icon.png — Number Run: Pro Edition app logo (512×512), used on-page and as the Open Graph/Twitter share image
- favicon.png / favicon-32.png / apple-touch-icon.png — browser tab and home-screen icons generated from icon.png
- robots.txt — crawler rules, points at sitemap.xml
- sitemap.xml — list of indexable pages

## GitHub Pages
Upload every file in this folder (including the .png assets and robots.txt/sitemap.xml) to the root of the public repository and enable Settings -> Pages -> Deploy from a branch -> main -> / (root).

## Updating the logo
If the app icon changes later, replace icon.png (ideally 512×512 or larger, square) and regenerate favicon.png (48×48), favicon-32.png (32×32) and apple-touch-icon.png (180×180) from it, then re-upload all four.
